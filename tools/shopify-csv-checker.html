Before you import

When you choose Shopify’s overwrite option, blank values in included columns can overwrite existing values. Columns omitted from the update file behave differently. Variant option columns can also affect variant IDs. This structure check only flags common patterns; review blank cells, Shopify’s import settings, and keep a backup of your original export. You are responsible for the import and its results. Ninjalens is not responsible for data loss or other damage arising from use of this tool or an import, to the maximum extent permitted by law.
